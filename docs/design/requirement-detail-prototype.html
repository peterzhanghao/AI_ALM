REQ-ALM-006 · 待推进

DSH 需求插件跨智能体 JSON 与 Excel 安全导入导出

要解决的问题

运营和客服需要把需求数据在浏览器里导出成 Excel，再交给另一个智能体批量导入。现在两边格式对不上——导出的表头导不回去，只能人工改一遍。这条需求把导入导出打通，并且保证导入前先校验权限和表头，出错时不会把整批数据写脏。

①原来这里是「原始需求」「AI 整理需求」两张卡并排，且首卡正文写的是「需求内容已由 AI 整理」这类元说明。改成一段 PM 结论，原文降到折叠里。
查看原始需求原文 2026-11-12 从对话整理
我要做一个需求插件的导入导出：需求能导成 Excel 给不装 DSH 的同事看，他们改完还能导回来；另外几个智能体之间也要能互相传需求 JSON。注意别把没权限的字段带出去，导错了整批别写进去。CSV 先不用管。

需要你确认：导入时遇到重复记录怎么办

同一份表里出现两条 ID 相同的记录时，是覆盖、跳过，还是整批不导入？选定后 AI 会继续。
