## 工具与证据边界

- 当前 Impeccable 安装版支持 `detect`，`critique` 和 `audit` 返回 `Unknown command`；UI 评审因此采用人工 Critique、Web Interface Guidelines 静态复核和可执行 detector，不伪造 CLI 报告。
- DSH Desktop 真实窗口已显示需求列表和澄清空态，但无法证明屏幕阅读器实际播报、系统缩放、真实成功模型流或供应商账单。
- 正式输出曾因 Desktop 映射 `client.js` 遇 Windows user-mapped section 锁；使用受支持的临时 `--outfile tmp/native-delivery/host.bundle.js` 完成编译验证，不等同于最新正式包已在运行中 Desktop 加载。
- 最新源码静态扫描未发现新的澄清/详情表单无障碍或图标按钮命名缺口；页签延迟焦点、窄面板横向溢出和焦点轮廓已有隔离回归。

需求插件的重构实现、隔离回归和审查任务已完成；发布验收尚未完成。任务 0–6 和 C9 不应勾选为整体完成，直到上述真实宿主、辅助技术、主题、性能和账单证据补齐。
